統計検定2級で頻出の記号の一覧。**「ハット（ ^ ）は推定量、バー（ ‾ ）は平均、ギリシャ文字は母集団の値、ローマ字は標本から計算した値」**という約束を覚えると、初見の式でも読み解ける。

## 1. 母集団と標本の対応

[[母集団]]の「本当の値（母数）」はギリシャ文字、標本から計算した値はローマ字で書き分けるのが慣習。

| 意味   | 母集団（母数）            | 標本（統計量）                                   | 補足                                    |
| ---- | ------------------ | ----------------------------------------- | ------------------------------------- |
| 個数   | $N$                | $n$                                       | 標本サイズは小文字の $n$                        |
| 平均   | $\mu$（ミュー）         | $\bar{x}$（エックスバー）                         | 確率変数として扱うときは $\bar{X}$ と大文字           |
| 分散   | $\sigma^2$（シグマ2乗）  | $s^2$                                     | $s^2$ は通常 $n-1$ で割る不偏分散 → [[分散・不偏分散]] |
| 標準偏差 | $\sigma$           | $s$                                       | 分散の平方根 → [[標準偏差]]                     |
| 比率   | $p$                | $\hat{p}$（ピーハット）                          | $\hat{p} = x/n$（該当数 ÷ 標本サイズ）          |
| 相関係数 | $\rho$（ロー）         | $r$                                       | → [[相関係数]]                            |
| 回帰係数 | $\beta_0, \beta_1$ | $\hat{\beta}_0, \hat{\beta}_1$ または $a, b$ | ハットは「推定した値」の印                         |

## 2. 確率変数と確率

| 記号                        | 読み方         | 意味                                  |
| ------------------------- | ----------- | ----------------------------------- |
| $X, Y$                    | 大文字         | 確率変数（値がまだ確定していない量）                  |
| $x, y$                    | 小文字         | 確率変数が実際に取った値（観測値）                   |
| $x_i$                     | エックスアイ      | $i$ 番目のデータ                          |
| $P(A)$                    | ピーエー        | 事象 $A$ が起こる確率                       |
| $P(A \mid B)$             | ビーが起きたときのエー | 条件付き確率。$B$ が起きたという条件のもとで $A$ が起こる確率 |
| $P(A \cap B)$             | エーかつビー      | $A$ と $B$ が両方起こる確率                  |
| $P(A \cup B)$             | エーまたはビー     | $A$ か $B$ の少なくとも一方が起こる確率            |
| $A^c$ または $\bar{A}$       | エーの余事象      | $A$ が起こらない事象                        |
| $X \sim N(\mu, \sigma^2)$ | チルダ         | 「$X$ は〜に従う」。右側に分布の名前を書く             |
| $f(x)$                    | 確率密度関数      | 連続型の分布の形を表す関数。面積が確率                 |
| $F(x)$                    | 累積分布関数      | $P(X \le x)$。$x$ 以下になる確率            |
| $\Phi(z)$                 | ファイ         | 標準正規分布の累積分布関数。正規分布表で引く値             |

## 3. 期待値・分散・共分散

| 記号 | 読み方 | 意味 | 参照 |
|---|---|---|---|
| $E[X]$ | イーエックス | 期待値（確率で重みづけした平均） | [[期待値]] |
| $V[X]$, $\mathrm{Var}(X)$ | ブイエックス | 分散 | [[分散・不偏分散]] |
| $\mathrm{Cov}(X, Y)$ | コバリアンス | 共分散 | [[共分散]] |
| $\mathrm{SE}$ | 標準誤差 | 標本平均のばらつき $\sigma / \sqrt{n}$ | |
| $x_i - \bar{x}$ | 偏差 | 各データと平均の差 | [[偏差]] |

## 4. 分布の記号

| 記号                        | 分布名    | パラメータの意味                                      |
| ------------------------- | ------ | --------------------------------------------- |
| $N(\mu, \sigma^2)$        | 正規分布   | 平均 $\mu$、分散 $\sigma^2$。2番目は分散であって標準偏差ではないので注意 |
| $N(0, 1)$                 | 標準正規分布 | 平均0、分散1。[[標準化]]するとこれになる                       |
| $B(n, p)$ または $Bin(n, p)$ | 二項分布   | 試行回数 $n$、成功確率 $p$                             |
| $Po(\lambda)$             | ポアソン分布 | 平均 $\lambda$（ラムダ）。平均と分散が等しい                   |
| $U(a, b)$                 | 一様分布   | $a$ から $b$ まで平ら                               |
| $t(k)$ または $t_k$          | t分布    | 自由度 $k$ → [[t分布]]                             |
| $\chi^2(k)$               | カイ2乗分布 | 自由度 $k$ → [[χ2乗分布]]                           |
| $F(m, n)$                 | F分布    | 自由度 $(m, n)$。分散分析で使う                          |

## 5. 推定・検定の記号

| 記号                   | 読み方           | 意味                                                |
| -------------------- | ------------- | ------------------------------------------------- |
| $\hat{\theta}$       | シータハット        | 母数 $\theta$ の推定量（ハット＝推定した値）                       |
| $\alpha$             | アルファ          | 有意水準。第1種の過誤（本当は差がないのに「ある」と言う）の確率。5%や1%            |
| $\beta$              | ベータ           | 第2種の過誤（本当は差があるのに「ない」と言う）の確率                       |
| $1 - \beta$          | 検出力           | 差があるときに正しく「ある」と言える確率                              |
| $H_0$                | 帰無仮説          | 「差がない」「効果がない」側の仮説。棄却されるのを待つ側                      |
| $H_1$                | 対立仮説          | 「差がある」側の仮説。示したい側                                  |
| $p$ 値                | ピーち           | 帰無仮説が正しいとして、観測値以上に極端な結果が出る確率                      |
| $z_{\alpha/2}$       | ゼットアルファにぶんのいち | 標準正規分布の上側 $\alpha/2$ 点。95%なら $z_{0.025} = 1.96$   |
| $t_{\alpha/2}(n-1)$  |               | 自由度 $n-1$ のt分布の上側 $\alpha/2$ 点。t分布表で引く            |
| $\chi^2_{\alpha}(k)$ |               | 自由度 $k$ のカイ2乗分布の上側 $\alpha$ 点                     |
| $Z$                  | 検定統計量         | 標準化した値 $\dfrac{\bar{X} - \mu}{\sigma / \sqrt{n}}$ |
| $\nu$ または $df$       | ニュー           | 自由度 → [[自由度]]                                     |
| $\text{i.i.d.}$      | アイアイディー       | 独立に同一の分布に従う。無作為抽出の数学的な言い換え                        |

## 6. 回帰分析の記号

| 記号 | 意味 |
|---|---|
| $y = \beta_0 + \beta_1 x + \varepsilon$ | 母集団の回帰モデル。$\varepsilon$（イプシロン）は誤差項 |
| $\hat{y} = a + bx$ | 推定した回帰直線。$a$ が切片、$b$ が傾き |
| $e_i = y_i - \hat{y}_i$ | 残差。実測値と予測値の差 |
| $R^2$ | 決定係数。回帰で説明できる割合（0〜1） |
| $S_{xy}, S_{xx}$ | 偏差積和・偏差平方和。$b = S_{xy} / S_{xx}$ |

## 7. 計算でよく出る記号

| 記号 | 読み方 | 意味 |
|---|---|---|
| $\sum_{i=1}^{n} x_i$ | シグマ | $x_1 + x_2 + \cdots + x_n$ を全部足す |
| $\prod_{i=1}^{n} x_i$ | パイ | 全部かける |
| $n!$ | エヌの階乗 | $n \times (n-1) \times \cdots \times 1$ |
| ${}_n C_r$ または $\binom{n}{r}$ | コンビネーション | $n$ 個から $r$ 個選ぶ組合せの数 |
| $\approx$ | ニアリーイコール | 近似的に等しい（中心極限定理で正規近似するときなど） |
| $\propto$ | 比例 | 比例する |
| $\infty$ | 無限大 | $n \to \infty$ で「$n$ を限りなく大きくする」 |
| $\exp(x)$ | エクスポネンシャル | $e^x$ のこと。$e \approx 2.718$ |
| $\ln x$ | 自然対数 | 底が $e$ の対数 |

## 8. ギリシャ文字の読み方まとめ

| 文字 | 読み | 統計での主な用途 |
|---|---|---|
| $\mu$ | ミュー | 母平均 |
| $\sigma$ | シグマ（小文字） | 母標準偏差 |
| $\Sigma$ | シグマ（大文字） | 総和 |
| $\rho$ | ロー | 母相関係数 |
| $\lambda$ | ラムダ | ポアソン分布・指数分布のパラメータ |
| $\alpha$ | アルファ | 有意水準 |
| $\beta$ | ベータ | 第2種の過誤、回帰係数 |
| $\chi$ | カイ | カイ2乗分布 |
| $\varepsilon$ | イプシロン | 誤差項 |
| $\theta$ | シータ | 一般の母数（何でも入る記号） |
| $\nu$ | ニュー | 自由度 |
| $\pi$ | パイ | 円周率、または母比率（$p$ の代わりに使う本もある） |
| $\Phi$ | ファイ（大文字） | 標準正規分布の累積分布関数 |
