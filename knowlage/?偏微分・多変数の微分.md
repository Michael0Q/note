| 概念            | 説明                                                                                                                                                                   |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 勾配 $\nabla f$ | 各変数の偏微分を並べたベクトル $\left(\frac{\partial f}{\partial x_1}, \dots\right)$                                                                                                |
| 多変数の連鎖律       | $\frac{\partial z}{\partial x} = \frac{\partial z}{\partial u}\frac{\partial u}{\partial x} + \frac{\partial z}{\partial v}\frac{\partial v}{\partial x}$（複数経路は和を取る） |
| ヤコビアン         | ベクトル値関数の一階偏微分行列                                                                                                                                                      |
| ヘッセ行列         | 二階偏微分の行列（二次最適化・ニュートン法で使用）                                                                                                                                            |
