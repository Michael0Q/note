
| ルール        | 式                                                 |
| ---------- | ------------------------------------------------- |
| 積の指数法則     | $a^m \cdot a^n = a^{m+n}$                         |
| 商の指数法則     | $a^m / a^n = a^{m-n}$                             |
| べき乗の指数法則   | $(a^m)^n = a^{mn}$                                |
| 負の指数 → 逆数  | $a^{-n} = \dfrac{1}{a^n}$                         |
| 分数の指数 → 根号 | $a^{1/n} = \sqrt[n]{a}$、$a^{m/n} = \sqrt[n]{a^m}$ |
| ゼロ乗        | $a^0 = 1$ ($a \neq 0$)                            |
| 積の分配       | $(ab)^n = a^n b^n$                                |
| 商の分配       | $(a/b)^n = a^n/b^n$                               |
