
| **操作**                 | **式**                                                                    |
| ---------------------- | ------------------------------------------------------------------------ |
| 分母の積を分解                | $\dfrac{1}{ab} = \dfrac{1}{a} \cdot \dfrac{1}{b}$                        |
| 分子の和を分解                | $\dfrac{a+b}{c} = \dfrac{a}{c} + \dfrac{b}{c}$                           |
| 分母の和は分解**できない**（頻出の誤り） | $\dfrac{1}{a+b} \neq \dfrac{1}{a} + \dfrac{1}{b}$                        |
| 部分分数分解                 | $\dfrac{1}{a(a+1)} = \dfrac{1}{a} - \dfrac{1}{a+1}$                      |
| 2乗の分母を積に分解             | $\dfrac{1}{a^2} = \dfrac{1}{a}\cdot\dfrac{1}{a}$（$a^{-2}=(a^{-1})^2$の意味） |
| 掛け算＝分母同士・分子同士          | $\dfrac{a}{b}\cdot\dfrac{c}{d} = \dfrac{ac}{bd}$                         |
| 割り算＝逆数の掛け算             | $\dfrac{a/b}{c/d} = \dfrac{a}{b}\cdot\dfrac{d}{c}$                       |
