関数の出力を近似する考え方。関数Fが無限に微分可能であれば、下記が成り立つ。
$$f(x) = \sum_{k=0}^{n-1}\frac{f^{(k)}(a)}{k!}(x-a)^k + R_n(x,a)$$

なお、第一項はPと表し、n-1次近似多項式と呼ぶ。のn-1は自分で決めることが可能。次数が上がるごとに元の関数に近似していく。（情報が増える）
0次は水平、1次は直線（高さ・傾きがある）、2次は放物線、3次以降はさらに柔軟な曲線...という風に字数が上がるごとに滑らかな曲線を描く。
$$P_{n-1}(x,a) = \sum_{k=0}^{n-1}\frac{f^{(k)}(a)}{k!}(x-a)^k$$


Rは剰余項といい、近似したn-1までの関数の総和に対して出る、元の関数とのズレの部分。
$$R_n(x,a) = \frac{f^{(n)}(c)}{n!}(x-a)^n$$

## 例
$f(x) = x^3$ を $x = a$ のまわりでテイラー展開する。

各階の微分:

$$f'(x) = 3x^2, \quad f''(x) = 6x, \quad f'''(x) = 6, \quad f^{(4)}(x) = 0$$

一般の点 $a$ を中心とした展開（公式に当てはめる）:

$$x^3 = a^3 + 3a^2(x-a) + \frac{6a}{2!}(x-a)^2 + \frac{6}{3!}(x-a)^3$$

整理すると:

$$x^3 = a^3 + 3a^2(x-a) + 3a(x-a)^2 + (x-a)^3$$

（$f^{(4)} = 0$ なので剰余項は $0$、これは恒等式）

$a = 1$ のまわりの場合:

$$x^3 = 1 + 3(x-1) + 3(x-1)^2 + (x-1)^3$$
