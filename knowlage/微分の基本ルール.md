| ルール                 | 式                                                     |
| ------------------- | ----------------------------------------------------- |
| べき乗則                | $\dfrac{d}{dx}x^n = nx^{n-1}$                         |
| 定数倍                 | $\dfrac{d}{dx}[cf(x)] = cf'(x)$                       |
| 和の微分                | $(f+g)' = f' + g'$                                    |
| 積の微分（積の法則）          | $(fg)' = f'g + fg'$                                   |
| 商の微分                | $\left(\dfrac{f}{g}\right)' = \dfrac{f'g - fg'}{g^2}$ |
| **連鎖律（chain rule）** | $\dfrac{d}{dx}f(g(x)) = f'(g(x))\cdot g'(x)$          |
| $e^x$ の微分           | $\dfrac{d}{dx}e^x = e^x$                              |
| $\log x$ の微分        | $\dfrac{d}{dx}\ln x = \dfrac{1}{x}$                   |
| シグモイドの微分            | $\sigma'(x) = \sigma(x)(1-\sigma(x))$                 |
