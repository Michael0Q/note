| ルール           | 式                                                        |
| ------------- | -------------------------------------------------------- |
| 転置の分配（順序が逆転）  | $(AB)^T = B^T A^T$                                       |
| 逆行列の分配（順序が逆転） | $(AB)^{-1} = B^{-1} A^{-1}$                              |
| 転置の転置         | $(A^T)^T = A$                                            |
| 逆行列と転置の交換     | $(A^{-1})^T = (A^T)^{-1}$                                |
| スカラーは転置しても不変  | $x^T A y$ はスカラーなので $(x^T A y)^T = y^T A^T x$ に等しい        |
| トレースの巡回性      | $\mathrm{tr}(ABC) = \mathrm{tr}(CAB) = \mathrm{tr}(BCA)$ |
| 分配法則          | $A(B + C) = AB + AC$                                     |
| **非可換性**      | 一般に $AB \neq BA$（順序を変えられない）                              |

## 行列微分
| 対象 | 微分結果 |
| --- | --- |
| $\frac{\partial}{\partial x}(a^T x)$ | $a$ |
| $\frac{\partial}{\partial x}(x^T A x)$ | $(A + A^T)x$（$A$ が対称なら $2Ax$） |
| $\frac{\partial}{\partial X}\mathrm{tr}(AX)$ | $A^T$ |
| $\frac{\partial}{\partial x}\lVert Ax - b \rVert^2$ | $2A^T(Ax - b)$（最小二乗法・線形回帰の正規方程式の導出） |
