| ルール            | 式                                    |
| -------------- | ------------------------------------ |
| 積 → 和          | $\log(ab) = \log a + \log b$         |
| 商 → 差          | $\log(a/b) = \log a - \log b$        |
| べき乗 → 係数       | $\log(a^n) = n\log a$                |
| 底の変換           | $\log_b a = \dfrac{\ln a}{\ln b}$    |
| log と exp の逆関係 | $\log(e^x) = x,\quad e^{\log x} = x$ |
| $\log(1) = 0$  |                                      |
