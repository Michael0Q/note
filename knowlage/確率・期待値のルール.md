| ルール            | 式                                                      |
| -------------- | ------------------------------------------------------ |
| 期待値の線形性        | $E[aX+bY] = aE[X]+bE[Y]$（$X,Y$ の独立性は不要）                |
| 分散の性質          | $\text{Var}(aX) = a^2\text{Var}(X)$                    |
| 独立な変数の分散       | $\text{Var}(X+Y) = \text{Var}(X)+\text{Var}(Y)$（独立時のみ） |
| 分散の別表現         | $\text{Var}(X) = E[X^2] - (E[X])^2$                    |
| 同時確率の分解（独立時）   | $P(A,B) = P(A)P(B)$                                    |
| 条件付き確率（ベイズの定理） | $P(A\mid B) = \dfrac{P(B\mid A)P(A)}{P(B)}$            |
| 周辺化            | $P(A) = \sum_b P(A,B=b)$                               |
