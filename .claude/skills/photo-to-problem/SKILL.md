試験問題を撮った写真から、このvaultのSRS形式の問題ノートを作成する。
**問題文の書き起こしや解答・解説は書かない。** 写真そのものを問題文としてノートに埋め込み、本文は「回答プロセス」「復習メモ」の空欄のみとする（書き起こしは誤読リスクがあるため原本写真を正とする）。

## 引数

`$ARGUMENTS` に写真のファイルパス（複数可）。試験名・級が分かればそれも。

## 手順

### 1. 画像の変換

HEICはReadで直接読めないため、`sips` でJPEGに変換する。作業はscratchpadディレクトリで行う。

```
sips -s format jpeg --resampleWidth 1600 <入力.HEIC> --out <scratchpad>/<名前>.jpg
```

### 2. 読み取りと向きの補正（重要）

**画像は逆さま（180°）や横向き（90°）の可能性がある。** 本の見開きを撮った写真では、下側ページを本を回さずに撮ることが多く、逆さまが頻発する。

- まず全画像をReadで読む
- 文字が逆さま・横向きで読み取れない画像は、`sips -r 180`（または `-r 90` / `-r 270`）で回転し、解像度を上げて（`--resampleWidth 2000` 程度）再変換してから読み直す
- 逆さまでも「読めた気になれる」ことがあるので、内容が不自然なら向きを疑う

読み取る目的は、①試験の実施年月・問番号の特定、②各問が「ざっくり何の問題か」の把握（ファイル名に使う）、③大問の区切りの特定。

### 3. 写真の添付保存

向きを補正した写真を `exam/添付/` に保存する:

- ファイル名: `<年月>_問<N>_原本.jpg`（例: `2021年6月_問3_原本.jpg`）
- 大問ごとに1枚（該当ページ全体でよい）。散布図など図だけ切り出す場合は `<年月>_問<N>_散布図.jpg` のように別ファイルにする
- **EXIF向きタグの正規化（必須）**: `sips -r` で回転してもEXIFのorientationタグが残り、タグを解釈するObsidianでは余計に90°回転して表示される（2026-09-09に全原本で発生・修正済み）。保存した各ファイルに対して必ず `python3 exam/スクリプト/normalize_exif_orientation.py <file.jpg>` を実行してタグを1にする。**その後Readで正立を再確認**する（タグ正規化後のReadが素のピクセルの向き＝Obsidianでの見え方になる）
- **`sips` のcropはEXIFの向き情報とズレて失敗しやすい**（cropは保存ピクセル座標で行われるが、Readでの表示はEXIF回転適用後のため、座標が転置・反転していることがある）。手順:
  1. まず適当な領域でテストcropしてReadで確認し、「表示座標→保存座標」のマッピング（転置・反転の有無）を特定する
  2. 例: iPhone縦持ち写真（EXIF orientation 6）では `保存x = 表示y`、`保存y = 画像幅 × (1 − 表示x)` になる
  3. マッピング確定後に本番の領域を切り出し、必ずReadで結果を目視確認する
  4. 2〜3回試してもズレるなら深追いせず全体画像のまま使う

### 4. ノート作成

`template/exam/新規問題.md` を読み、Templater構文を手で評価した形でノートを作る:

- 保存先: `exam/問題/<ファイル名>.md`
- ファイル名: `<年月>_問<N>_<ざっくり何の問題か>.md`
  - 年月は写真から読み取る（例: `2021年6月`）
  - 例: `2021年6月_問3_パーシェ指数の計算`、`2021年6月_問5_散布図と共分散・相関係数`
- frontmatter: テンプレート通り（`tags: [problem]`, `category`, `level: 0`, `last: 今日の日付`, `status: ""`, `retired: false`）
- `category`: `<試験名>/<小項目>` 形式。分野部分は自由記述ではなく、**出題範囲表の「小項目」から最も近いものを1つ選ぶ**。統計検定2級（出題範囲表 2018/12/14版）の小項目一覧:
  - 身近な統計 / データの分布の記述 / 中心傾向の指標 / 散らばりなどの指標 / 中心と散らばりの活用 / 散布図と相関 / カテゴリカルデータ / 単回帰と予測 / 時系列データの処理 / 観察研究と実験研究 / 標本調査と無作為抽出 / 実験 / 確率 / 確率変数 / 確率分布 / 標本分布 / 推定 / 仮説検定 / 回帰分析 / 実験計画の概念の理解 / 統計ソフトウェアの活用
  - 例: パーシェ指数・成長率・幾何平均の問題 → `統計検定2級/時系列データの処理`、相関係数・共分散 → `統計検定2級/散布図と相関`
  - 迷ったら問題の主要な計算・判断が属する小項目を優先する（用語がどの小項目の「項目」欄にあるかで判断）
- **フォールバック（範囲外エラー）**: 問題の主題が上の小項目の**どれにも合理的に当てはまらない**場合（準1級以上の範囲と思われる場合。例: マルコフ連鎖、時系列モデル(AR/MA)、主成分分析、ベイズ推定の発展的内容など）、**その問題のノートは作成しない**。勝手に近そうな小項目へ押し込んだり、独自のカテゴリ名を発明したりしない。当てはまる問題のノートだけ作成し、範囲外の問題は完了報告でエラーとして扱う
- 本文: meta-bindボタン3つ（○△×）→ `## 回答プロセス`（空欄）→ `## 復習メモ`（空欄）→ **ページ末尾に原本写真の埋め込み** `![[<年月>_問<N>_原本.jpg]]`（図の切り出しがある場合はその直後に並べる）
- 分割の単位: **大問ごとに1ノート**（小問はまとめる）
- 「## 復習ログ」セクションは作らない（review.js が初回採点時に末尾へ自動生成する）

### 5. 完了報告

作成したノートの一覧（ファイル名と何の問題か）、読み取りに不安が残る箇所（向き・年月の判読など）を報告する。

範囲外でスキップした問題がある場合は、報告の冒頭に **「⚠️ 範囲外エラー」** として以下を明記する:

- どの写真のどの問題か（年月・問番号）
- 問題の主題と、なぜどの小項目にも当てはまらないと判断したか（例: 「AR(1)モデルの定常性 → 準1級範囲の時系列解析」）
- 対応の選択肢: そのままスキップ / 別試験名のカテゴリ（例: `統計検定準1級/◯◯`）で作る / 最も近い2級の小項目に寄せて作る — のどれにするかユーザーに確認する
