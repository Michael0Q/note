# 統計検定2級 問題画像の構成

`{試験回}/Q{問番号2桁}/question.jpg` の形式で配置（問番号はゼロ埋め2桁: `Q08` `Q14`）。複数ページにまたがる問は `question-2.jpg` 以降が続き。
解答の写真は同じフォルダに `answer.jpg`（複数ページなら `answer-2.jpg`…）として置く。

元のページ写真（`p○○.jpg`）は削除済み。ページ番号指定（「p14 解いて」）は下の対応表で問番号に変換して読む。
この階層の直下には photo-to-problem スキルが保存する原本写真（`2021年6月_問5_原本.jpg` 等）も置かれる。
