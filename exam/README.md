# exam-srs-vault — 資格試験用 間隔反復システム（Obsidian）

問題1問=1ノートで管理し、フィボナッチ間隔の間隔反復（Spaced Repetition）で「今日復習すべき問題」を自動抽出するObsidian vaultです。

## 仕組み

### 復習間隔ラダー

```
LADDER = [1, 2, 3, 5, 8, 13, 21, 34, 55]（単位: 日）
```

- `level` はラダーのインデックス（0〜8）
- **次回復習日 = last + LADDER[level] 日**。frontmatterには保存せず、常にダッシュボードのDataviewJSが計算する
- ただし `status: "×"` のときだけ **期限 = last + 1日** に上書き（翌日必ず出す）

### 判定と遷移

| ボタン | 意味 | 遷移 |
|---|---|---|
| ○ | 正解＋プロセスを自分の言葉で説明できた | level +2（上限8）。level>=7からの○なら `retired: true`（卒業） |
| △ | 正解したが説明できない（暗記止まり） | level +1（上限8） |
| × | 不正解 | level据え置き・last=今日。翌日必ずキューに出る |
| ×状態からの ○/△ | 翌日の再挑戦で正解 | **level = max(0, level-1)** に戻して再開（○/△共通の特別扱い） |

判定・遷移ロジックの実体は `exam/スクリプト/review.js` にあります。

### frontmatterスキーマ

```yaml
---
tags: [problem]
category: ""      # 分野（例: 民法/債権）
level: 0          # ラダー位置 0〜8
last: 2026-08-05  # 最終復習日（YYYY-MM-DD、引用符なし）
status: ""        # ○ / △ / ×
retired: false    # 卒業フラグ
---
```

## セットアップ

### 1. vaultとして開く

Obsidianで「Open folder as vault」→ このフォルダを選択。
（既存vaultに組み込む場合は `exam/` フォルダごとコピーしてください。その場合もフォルダ名・配置は `exam/` 直下のまま維持すること — スクリプトパスとDataviewの検索対象がこのパス前提です）

### 2. コミュニティプラグインのインストール

設定 → コミュニティプラグイン から以下4つをインストールして有効化:

| プラグイン | 役割 |
|---|---|
| **Dataview** | ダッシュボードの復習キュー・統計 |
| **Meta Bind** | 問題ノート内の ○/△/× ボタン |
| **JS Engine** | Meta Bindのボタンから `review.js` を実行するために必要 |
| **Templater** | 新規問題の登録フロー |

### 3. プラグイン設定

- **Dataview**: 設定で `Enable JavaScript Queries` を **ON**
- **Meta Bind**: JS Engineが入っていればjs actionは動作します（設定にJS実行の許可トグルがあるバージョンではONにする）
- **Templater**: `Template folder location` は vault 共通の `template`（このテンプレートは `template/exam/` 配下）。folder template で `exam/問題` → `template/exam/新規問題.md` を割り当て済み

### 4. CSSスニペットの有効化（ボタンの配色）

○/△/× ボタンのパステル配色は `.obsidian/snippets/srs-buttons.css` で定義しています。
設定 → 外観 → CSSスニペット でリロードボタンを押し、`srs-buttons` をONにしてください。
（有効化しなくても機能には影響なく、テーマ標準の配色になるだけです）

## 使い方

### 毎日の復習

1. `exam/ダッシュボード.md` を開く
2. 「今日の復習」テーブルの問題を上から解く
3. 各問題ノートの ○/△/× ボタンを1タップ → frontmatter更新＋「## 復習ログ」に1行追記される
4. キューが10件以上あると見出しに ⚠️ が出るので、その日は新規問題の追加を控える

### 新規問題の登録

1. コマンドパレット（Cmd+P）→ **「Templater: Create new note from template」** → `新規問題` を選択
2. 問題名（ファイル名）→ 分野 の順にプロンプトが出る
3. `exam/問題/` に `level: 0, last: 今日` で作成される

よく使うならTemplaterの `Template Hotkeys` ではなく、コマンドパレットのこの操作にホットキーを割り当てるのが安全です（挿入系コマンドは開いているノートを書き換えてしまうため）。

### 既存ノートのSRS化（knowlage配下など）

`exam/問題/` 以外のノートも、`#problem` タグとSRS用frontmatterが揃えば同じ仕組みに乗ります（`review.js` はタグしか見ておらず、ダッシュボードは `exam/問題` と `knowlage` の両方を検索対象にしています）。

1. SRS化したいノートを開き、○/△/× ボタンを置きたい位置にカーソルを置く
2. コマンドパレット → **「Templater: Open insert template modal」** → `SRS化` を選択
3. 分野を選ぶと、frontmatterにSRSフィールド（`tags: problem`, `level: 0`, `last: 今日` など。既存の値は上書きしない）が補われ、カーソル位置にボタンが挿入される

翌日から復習キューに出ます。一括で大量にSRS化するとキューが溢れるので、ダッシュボードの件数を見ながら少しずつ追加すること。

なお `ナレッジステータス.md`（knowlageの進捗集計）は `-#problem` でSRS化ノートを除外しているため、SRS化するとそちらの集計からは外れます。

## 動作確認

サンプル問題を3つ同梱しています（日付は2026-08-05にキューへ出る設定）:

1. **ダッシュボードを開く** → 「今日の復習: 3件」と3問のテーブルが出ることを確認
   - サンプル03は `level: 3`（本来なら5日間隔）だが `status: "×"` のため翌日=今日に出ている → ×の上書きロジックの確認
2. **サンプル01で○ボタンを押す** → `level: 0→2`, `last: 今日`, `status: ○` になり、復習ログに1行追記され、ダッシュボードから消えることを確認
3. **サンプル03（×状態）で○か△を押す** → `level: 3→2`（-1に戻る特別扱い）になることを確認
4. **卒業の確認**: 任意のサンプルの `level` を手で `7` に書き換えて○を押す → `retired: true` になり、キューにも統計の「回転中」にも出なくなることを確認

確認が済んだらサンプル3ファイルは削除してOKです。

## ファイル構成

```
exam/
  問題/                     # 問題ノート置き場（1問1ノート）
  スクリプト/review.js      # ○/△/× の判定・遷移ロジック
template/exam/新規問題.md   # Templaterテンプレート（新規問題の作成、ボタン込み）
template/exam/SRS化.md      # 既存ノート（knowlage等）をその場でSRS対象にする
ダッシュボード.md            # 今日の復習キュー＋統計（vaultルート）
```

## 実装上の注意（メンテナンス用）

- **タイムゾーン**: 日付はすべて `YYYY-MM-DD` の日付のみで保存し、比較は `startOf("day")` に正規化してから行う。時刻付き・UTC文字列を混ぜないこと
- **復習ログ**: `## 復習ログ` はテンプレートの最終セクションという前提で、ファイル末尾に追記している。ログの後ろにセクションを足さないこと
- **Dataviewの検索対象**: `("exam/問題" or "knowlage") and #problem` に限定している（テンプレート自体が集計に混入するのを防ぐため）。問題ノートは `exam/問題/` または `knowlage/` 配下に置き、必ず `#problem` を付けること
- ボタンを押しても動かない場合: JS Engineの有効化と、Meta Bindボタン内の `file: exam/スクリプト/review.js` のパスを確認
