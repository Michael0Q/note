# ナレッジステータス

## サマリ

```dataview
TABLE WITHOUT ID status AS "ステータス", length(rows) AS "件数"
FROM -"template"
WHERE status
GROUP BY status
SORT status DESC
```

## 未着手

```dataview
TABLE WITHOUT ID file.link AS "ノート", file.folder AS "場所"
FROM -"template"
WHERE status = "未着手"
SORT file.name ASC
```

## 進行中

```dataview
TABLE WITHOUT ID file.link AS "ノート", file.folder AS "場所", file.mtime AS "最終更新"
FROM -"template"
WHERE status = "進行中"
SORT file.mtime DESC
```

## 完了

```dataview
TABLE WITHOUT ID file.link AS "ノート", file.folder AS "場所", file.mtime AS "最終更新"
FROM -"template"
WHERE status = "完了"
SORT file.mtime DESC
```
